# Calvo 2500

Landing estática para el desarrollo inmobiliario de Carlos Calvo 2500, San Cristóbal.

## Desarrollo local

Abrí `index.html` directamente o ejecutá un servidor estático, por ejemplo:

```bash
python3 -m http.server 8080
```

## Netlify

No requiere comando de build. El directorio de publicación es la raíz del repositorio (`.`).

Antes de publicar, revisar los pendientes de `CONTEXT.md`.
